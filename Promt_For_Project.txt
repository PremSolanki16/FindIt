# PROJECT MASTER PROMPT – FINDIT (LOST & FOUND PLATFORM)

## 1. Project Overview

I am building a full-stack web development project called **FindIt – Lost & Found Platform**.

FindIt is a web application designed to help people find their lost belongings and return found items to their rightful owners.

For example:
- A person loses their wallet in a college library.
- Another person finds that wallet.
- The finder creates a found-item post on FindIt.
- The actual owner searches for the wallet.
- The owner submits an ownership claim.
- The finder reviews the claim and accepts or rejects it.
- If accepted, both users communicate privately.
- Finally, the wallet is returned to its rightful owner.

The main objective is to develop a complete working full-stack application.

## 5. MongoDB Database Architecture

Database name: `findit`

Use MongoDB with Mongoose.

The database contains seven collections:

1. users
2. items
3. claims
4. conversations
5. messages
6. notifications
7. reports

### Collection Relationships

- One user can create multiple item posts.
- An item post belongs to a user through `createdBy`.
- A found item can receive multiple claims.
- A claim references a specific found item.
- A claim belongs to a claimant.
- A conversation references a claim and contains authorised participants.
- Messages belong to a conversation.
- Notifications belong to their recipients.
- Reports reference reported items, users or messages.

Use ObjectId references as described in the approved MongoDB database architecture.

Important:
- Lost and found posts share one `items` collection.
- The `type` field distinguishes `lost` and `found`.
- Claims must refer to found items.
- Do not change the approved collection architecture or introduce additional collections without my permission.
